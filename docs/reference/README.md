# Reference material

Put these here before starting the rebuild. Reference only; nothing in this
folder is shipped.

- `second-prototype/` : the source files of the navy "Idea Discovery Rooms"
  prototype (HTML, CSS, JavaScript, images).
- `screenshots/` : screenshots of that prototype.
- `feedback-document.pdf` : the printable four-page feedback document that
  goes to the owners alongside the app.

How to use it:
- Take the look (colours, spacing, cards, illustrations) from the prototype.
- Take the pallet project's wording from the feedback document, so the app
  and the paper say the same thing.
- Do not copy the prototype's code structure. Rebuild in the project's stack.
- Where this folder and docs/design.md disagree, docs/design.md wins.
